# ชุดเตรียมสอบ TEGS

เครื่องมือเตรียมสอบ CMU-TEGS แบบ static HTML เปิดใช้งานได้ทันทีในเบราว์เซอร์ ไม่ต้องติดตั้งอะไรเพิ่ม

## ไฟล์ในโปรเจกต์

- **`tegs-suite.html`** — แอปรวมทุกอย่างในไฟล์เดียว (แนะนำให้เปิดไฟล์นี้) มีเมนูสลับ 3 ส่วน:
  - 📘 ไวยากรณ์
  - 🎧 ข้อสอบจำลอง
  - 📚 คำศัพท์
- `tegs-grammar-guide.html` — คู่มือไวยากรณ์ TEGS แยกไฟล์เดี่ยว
- `tegs-practice-app.html` — ข้อสอบจำลอง 80 ข้อ 150 นาที 3 ชุด (มีเสียงฟังจริงในเบราว์เซอร์) แยกไฟล์เดี่ยว
- `tegs-vocab-bank.html` — คลังคำศัพท์ 1,000 คำ ฝึกฟัง/พูดตาม/อ่าน/เขียน แยกไฟล์เดี่ยว

## วิธีใช้งาน

ดาวน์โหลดหรือ clone แล้วเปิดไฟล์ `.html` ที่ต้องการด้วยเบราว์เซอร์โดยตรง (ดับเบิลคลิก หรือ `File > Open`)

เปิดไฟล์ตรง ๆ (ไม่ใช่ผ่านหน้าเว็บที่ห่อด้วย iframe) จะทำให้ระบบเสียงพูด (Web Speech API) ทำงานได้เต็มที่

## ฟีเจอร์เด่น

- **ข้อสอบจำลอง**: โครงสร้างตรงกับข้อสอบจริง (Listening 20 / Structure 20 / Vocabulary 20 / Reading 20 = 80 ข้อ) มีทั้งโหมดฝึกฝนและโหมดสอบจริงจับเวลา
- **คำศัพท์ 1,000 คำ**: ระบบจำสถานะต่อคำ (ยังไม่เรียน / กำลังจำ / จำได้แล้ว) บันทึกในเครื่องผ่าน localStorage
- **ไวยากรณ์**: อธิบายจุดที่ออกสอบซ้ำเป็นภาษาไทย พร้อมตัวอย่างจริงจากข้อสอบ

ไม่มี backend, ไม่มี dependency ภายนอก — เป็นไฟล์ HTML/CSS/JS ล้วน ๆ
